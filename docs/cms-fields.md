# microCMS フィールド一覧（手作業で API を作るとき用）

> このファイルは `cms/schema/*.json` から作った一覧です。ふつうは管理画面の「スキーマをインポート」で JSON を読み込めば作れます。インポートが使えないときだけ、この表のとおりに手で作ってください。
> **フィールド ID は表のとおりに**してください（違うとサイトが読めません）。表示名と説明は変えてもかまいません。
> カスタムフィールドは、それを使う API・カスタムフィールドより **先に** 作ってください（繰り返しの中のカスタムフィールドは、さらにその中身を先に）。

## サイト設定（エンドポイント `settings`・オブジェクト形式）

### API のフィールド

| フィールド ID | 表示名 | 種類 | 必須 | 設定 | 説明 |
|---|---|---|---|---|---|
| `siteTitle` | サイトのタイトル | テキストフィールド | 必須 |  | ブラウザのタブや検索結果に出る名前です。 |
| `description` | 検索結果の説明文 | テキストエリア |  |  | Google などの検索結果に出る説明です。120字くらいまで。 |
| `ogDescription` | SNS で共有したときの説明 | テキストエリア |  |  | 空なら「検索結果の説明文」を使います。 |
| `ogImage` | SNS で共有したときの画像 | 画像 |  |  | 横長（1200×630 くらい）。空なら今の画像のままです。 |
| `jsonldDescription` | 検索エンジン向けの団体紹介 | テキストエリア |  |  | 1〜2文の短い紹介。空なら「検索結果の説明文」を使います。 |
| `lineUrl` | 公式LINE の URL | テキストフィールド | 必須 |  | https:// から。サイト中の LINE ボタンはすべてここに飛びます。 |
| `lineId` | 公式LINE の ID | テキストフィールド |  |  | 例: @990qouib（表示用） |
| `instagramUrl` | Instagram の URL | テキストフィールド |  |  | https:// から。空なら Instagram の表示を出しません。 |
| `instagramId` | Instagram の ID | テキストフィールド |  |  | 例: @nagasaki_childhome（表示用） |
| `facebookUrl` | Facebook の URL | テキストフィールド |  |  | https:// から。空なら出しません。 |
| `linkedinUrl` | LinkedIn の URL | テキストフィールド |  |  | https:// から。空なら出しません。 |
| `email` | メールアドレス | テキストフィールド | 必須 |  | お問い合わせ先。サイト中のメールのリンクはすべてここに届きます。 |
| `footerText` | フッターの紹介文 | テキストエリア |  |  | ページ最下部の団体名・紹介文。改行するとそこで行が変わります。 |
| `copyright` | 著作権表示の名前 | テキストフィールド |  |  | 「© 2026」の後ろに出る名前です。年は自動で入ります。 |
| `stickyText` | スマホ下部の固定バー：文 | テキストフィールド |  |  | 例: 参加してみたい？ |
| `stickySub` | スマホ下部の固定バー：小さい文 | テキストフィールド |  |  | 例: 質問だけでも大丈夫 |
| `stickyButton` | スマホ下部の固定バー：ボタン | テキストフィールド |  |  | 押すと公式LINE が開きます。 |
